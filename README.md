# sf-advanced-extension
Advanced Salesforce browser extension for org inspection, metadata comparison, data explorer, and automation tools..


## How to use this extension

1. Open Salesforce org and login into it.
2.go to chrome extensions
3. Enable developer mode
4. Click on load unpacked
5. Select the extension folder
6. Click on the extension icon
7.select connect to org
8.enter the CURRENT TAB / org url and session id /salesforce login url.
9.click on connect
10. Select the feature you want to use

## 🌟 Features

*   **🔍 Visual SOQL Builder:** Construct complex Salesforce Object Query Language (SOQL) queries visually without writing syntax manually. Easily select fields, relationships, filters, and limits with an intuitive interface.
*   **▶️ Query Runner:** Execute SOQL queries rapidly. Features include recent query history, JSON or Table view toggling, syntax formatting, and easy CSV/JSON exporting.
*   **📦 Metadata Explorer:** Search and explore your Salesforce org's objects, examining properties and field metadata quickly.
*   **📤 Data Loader:** Perform Insert, Update, Upsert, and Delete operations effortlessly. Supports drag-and-drop CSV file uploads with an interactive preview before processing data changes.
*   **🌐 Schema Viewer:** Generate a visual relationship graph for objects to easily understand your data model structure and field connections.
*   **⚖️ Org Comparator:** Connect and compare metadata seamlessly between two different orgs (e.g., Sandbox vs. Production). Highlights differences in Objects, Fields, Apex Classes, and Profiles.
*   **🤖 AI Assistant:** Get intelligent, context-aware help! Ask for SOQL query generation, Apex code explanations, governor limit assistance, and general Salesforce troubleshooting.
*   **🐞 Apex Debug Helper:** Quickly analyze generic Apex errors, stack traces, and fetch recent debug logs for faster root-cause analysis.
*   **📦 Package.xml Generator:** Select various metadata components (e.g., Apex Classes, LWC, Layouts, Permission Sets) and automatically generate a valid `package.xml` manifest tailored for your deployment needs.
