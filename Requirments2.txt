# Powerful Master Prompt for Building a Salesforce Developer Chrome Extension

You are a senior software architect and Salesforce platform expert.

Design and generate the complete architecture, system design, and development roadmap for a professional Chrome/Edge browser extension that acts as an advanced Salesforce developer toolkit similar to Salesforce Inspector and FuseKit.

The extension must be designed for Salesforce developers and admins and should significantly improve productivity when working with Salesforce data, metadata, SOQL queries, debugging, and multi-org management.

The system must follow Chrome Extension Manifest V3 architecture and be built using modern scalable technologies.

---

PRIMARY OBJECTIVE

Build a powerful Salesforce Developer Chrome Extension that supports:

• Multi-org Salesforce connections
• Visual SOQL query builder
• Relationship-aware query generation
• Metadata explorer
• Data loader and bulk data editor
• Schema graph viewer
• Apex debug assistant
• Org comparison tools
• AI-powered query generator
• Package.xml generator

The extension must work with both Chrome and Edge browsers.

---

AUTHENTICATION & SECURITY

Implement Salesforce OAuth authentication.

Requirements:

1. Use OAuth 2.0 authentication with Salesforce
2. Allow login to multiple Salesforce orgs (production, sandbox, developer orgs)
3. Store access tokens securely using Chrome extension storage APIs
4. Handle token refresh automatically
5. Allow users to switch orgs easily
6. Support login to multiple Salesforce domains

OAuth endpoints:

/services/oauth2/authorize
/services/oauth2/token
